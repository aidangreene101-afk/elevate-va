# Marvel Cinematic Universe — Timeline Guide

A reference list of the MCU movies and Disney+ shows, with every show broken
down episode by episode. Two views are included:

1. **Chronological (in-universe) order** — the order events happen in the story.
2. **Release order** — the order things actually came out, with full episode lists for the shows.

> Note: The MCU's official in-universe timeline shuffles some show episodes
> between movies. The chronological list below places each title at its main
> story point; for episode-level detail use the Release Order section.
